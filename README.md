### 01. DealLens
**AI-assisted contract comparison and impact analysis**

[![Repository](https://img.shields.io/badge/Source_Code-181717?style=flat-square&logo=github)](https://github.com/aryan24cse109-dev/DealLens)
[![Live App](https://img.shields.io/badge/Live_Application-00A86B?style=flat-square&logo=vercel&logoColor=white)](https://deal-lens-ten.vercel.app)
[![Demo](https://img.shields.io/badge/Watch_Demo-FF0000?style=flat-square&logo=youtube)](https://youtu.be/XoIwsZcT97A)

DealLens helps freelancers, developers and agencies understand changes between two versions of a contract.

Instead of manually comparing lengthy agreements, users can upload original and revised PDFs, identify added, removed and modified content, and review the potential impact of each change.

**Engineering highlights**
- PDF text extraction and document comparison.
- Rule-based change classification and severity assessment.
- Structured AI-assisted impact analysis.
- Validated AI responses and persistent analysis records.
- Exportable PDF, TXT and JSON reports.
- Editable client clarification email drafts.

**Stack:** React, Vite, Node.js, Express, PostgreSQL, Prisma, Groq, Zod.

### 03. IntelliLandAI
**AI-powered land record digitization, validation and GIS parcel linking**

[![Repository](https://img.shields.io/badge/Source_Code-181717?style=flat-square&logo=github)](https://github.com/aryan24cse109-dev/intellilandAI)
[![Live App](https://img.shields.io/badge/Live_Demo-00A86B?style=flat-square&logo=vercel&logoColor=white)](https://intelliland-auvb9qa8u-bhumatrix.vercel.app/login)
[![Demo](https://img.shields.io/badge/Watch_Demo-FF0000?style=flat-square&logo=youtube)](https://youtu.be/6ntKG6ohBbA)

IntelliLandAI explores how AI and geospatial technology can help digitize and validate scanned land-record documents.

The system extracts structured information from documents, compares it against reference data, flags discrepancies for human verification and connects records with GIS parcels for map-based visualization.

**Engineering highlights**
- Document preprocessing and OCR.
- LLM-assisted structured field extraction.
- Reference-data validation and discrepancy detection.
- Human-in-the-loop review and correction.
- GIS parcel linking and interactive map visualization.
- Role-based access control and audit history.

**Stack:** React, Vite, Node.js, Express, FastAPI, PostgreSQL, PostGIS, OCR, OpenCV, Leaflet.

*Note: This is a working prototype using synthetic/demo data, not an official government land-record system.*

### 04. Return-Rate-Reducer
**Multi-dimensional product return-risk analysis system**

[![Repository](https://img.shields.io/badge/Source_Code-181717?style=flat-square&logo=github)](https://github.com/aryan24cse109-dev/Return-Rate-Reducer)
[![Live Dashboard](https://img.shields.io/badge/Live_Dashboard-00A86B?style=flat-square)](https://aryan2323-return-rate-reducer.hf.space/dashboard)
[![API Docs](https://img.shields.io/badge/API_Documentation-4169E1?style=flat-square)](https://aryan2323-return-rate-reducer.hf.space/docs)

An analytical system designed to estimate order return risk using customer history, delivery experience, product quality, payment method, pricing sensitivity and review sentiment.

It combines a multi-dimensional risk matrix with an ML-based prediction component and exposes the analysis through an API and interactive dashboard.

**Engineering highlights**
- Multi-dimensional rule-based risk scoring.
- XGBoost-based return probability prediction.
- FastAPI REST endpoints for individual and batch analysis.
- Interactive dashboard with CSV batch processing.
- Risk-factor explanations and recommended actions.
- Automated testing and GitHub Actions CI pipeline.

**Stack:** Python, FastAPI, XGBoost, Streamlit, Pandas, Scikit-learn, Docker.
